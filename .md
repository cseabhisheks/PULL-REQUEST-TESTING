## Node.js Events Module

**Purpose:** Used to create, emit, and handle custom events using `EventEmitter`.

### Example covering `on()`, `emit()`, `once()`, and `off()`

```js
const EventEmitter = require("node:events");

const event = new EventEmitter();

// on(): Runs every time the event is emitted
const greet = () => {
  console.log("Hello, welcome!");
};

event.on("greet", greet);

// once(): Runs only one time
event.once("login", () => {
  console.log("User logged in");
});

// emit(): Triggers the events
event.emit("greet");
event.emit("login");
event.emit("login");

// off(): Removes the registered listener
event.off("greet", greet);

event.emit("greet");
```

**Output:**

```text
Hello, welcome!
User logged in
```

### Important Methods

| Method | Purpose |
|---|---|
| `on()` | Registers a listener that can run multiple times. |
| `emit()` | Triggers an event. |
| `once()` | Runs a listener only once. |
| `off()` | Removes a registered listener. |
